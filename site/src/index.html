Five checks, one command

Pattern-based and fast. Built for the new attack surface: text that tells an AI model what to do.

AI & MCP risksai

Instruction overrides, “don’t tell the user,” exfiltration requests and auto-approve prompts in skills, prompts and MCP tool descriptions. Invisible Unicode smuggling, decoded so you can read it.

Permission manifestmanifest

Declare what a component touches — network, files, env, subprocesses. Coticula flags code that reaches further than it says.

Secretssecrets

Anthropic, OpenAI, AWS, GitHub, Slack and Stripe keys, private keys, committed .env files, high-entropy hard-coded values. Always redacted in output.

Vulnerable dependenciesdeps

Pinned Python and npm packages checked against OSV.dev. Unpinned versions flagged so what you scan is what you ship.

Quality scorequality

Tests that can’t fail, missing docs, placeholders, swallowed errors. A 0–100 score that keeps the slop out.

Where this is going

The scanner is phase one of an open, vetted library of parts people can bolt onto their projects — so nobody has to build the same thing twice.

  • NowScanner CLI, CI integration, Scanned badge. Free.
  • NextThe catalog: a searchable library of vetted components, browsable by people and queryable by agents over MCP.
  • ThenThe Collegium: a community of builders with requests and bounties, a reviewer guild, team plans and paid components.
